# 📱 SmartQ – Smart Queue Management System

## 📖 Overview
SmartQ is a mobile application UI/UX design developed in Figma to simplify queue management across multiple service sectors. The application enables users to join virtual queues, track their queue status in real time, receive notifications, and provide feedback after their visit.

## ✨ Features
- User Registration and Login
- Service Category Selection
- Branch Selection
- Virtual Queue Booking
- Live Queue Status Tracking
- Real-Time Notifications
- User Profile Management
- Queue Join Confirmation
- Turn Reminder
- Queue Completion Notification
- Feedback and Rating

## 🏢 Supported Services
- 🏥 Hospitals
- 🏦 Banks
- 🍽️ Restaurants
- 🏛️ Government Offices

## 🛠️ Tools & Technologies
- Figma
- UI/UX Design
- Interactive Prototyping

## 🎯 Objective
The objective of SmartQ is to reduce waiting time by allowing users to reserve a virtual queue before arriving at a service location. The application enhances user convenience, improves service efficiency, and provides a seamless queue management experience across different sectors.
